# Красная нить

Кооперативный детектив на компанию: 2–10 телефонов и один большой экран. В главном меню — миры,
в каждом мире — своя бригада сыщиков со своими способностями, своё оформление, музыка и звук,
и дела. За одну ночь бригада должна назвать имя, способ и причину.

Это репозиторий движка: сервер, экран, телефон, миры и бригады, инструменты генерации.
**Дела с разгадками лежат в отдельном закрытом репозитории `red-thread-secret`** — чтобы разгадку
нельзя было случайно прочитать в коде. Спойлеров в этом репозитории нет.

## Миры

- **Нуар** — пятидесятые, дождь, телефонные будки, бригада городского управления.
- **Неон** — 2081 год, Новая Пальмира, Отдел 9.

## Быстрый старт дома (Docker)

Нужны Docker Desktop (или Docker Engine) и доступ к репозиторию дел.

```bash
mkdir red-thread && cd red-thread
git clone git@github.com:flamediman/red-thread-public.git
git clone git@github.com:flamediman/red-thread-secret.git
cd red-thread-public
cp .env.example .env          # CASES_DIR=../red-thread-secret уже прописан
PORT=3100 docker compose up -d --build
```

- Экран (телевизор или ноутбук): `http://127.0.0.1:3100/`. Кода ведущего нет: экраном становится тот, кто открыл
  главную страницу.
- Нажмите «Начать игру» — это разблокирует звук. Стрелками, клавишами ← → или свайпом листайте миры,
  выберите дело.
- Телефоны сканируют QR из лобби. Телефоны и ноутбук должны быть в одной сети Wi‑Fi.

Остановить: `docker compose stop`. Партия переживает перезапуск сервера и перезагрузку экрана или
телефона. Сброс партии: остановить, удалить `.data/game.json`, запустить. История сыгранных дел
остаётся в `.data/history.json`.

Без репозитория дел сервер тоже запустится, но меню честно скажет, что дел нет.

## Без Docker

Нужен Node.js 24.

```bash
npm ci
npm run build
node .output/server/index.mjs     # переменные — из окружения, см. таблицу ниже
```

Разработка с горячей перезагрузкой: `npm run dev` (порт 3000, файл `.env` подхватывается сам).

## Два режима

| | Дома (`GAME_MODE=local`) | В сети (`GAME_MODE=public`) |
|---|---|---|
| Партии | одна на сервер | много комнат одновременно |
| Экран входит | сразу, по главной странице | кнопкой «Открыть комнату» — без регистрации |
| Телефоны | по QR с IP ноутбука в Wi‑Fi | по QR или коду комнаты из шести знаков |
| Фото игроков | можно | выключены: персональные данные не собираются |
| Снимки партий | `.data/game.json` | `.data/rooms/<код>.json`, пустые комнаты закрываются сами |

Режим «в сети» рассчитан на сервер за обратным прокси (Caddy, nginx) и CDN: включите `TRUST_PROXY=1`
и укажите `REAL_IP_HEADER`, иначе ограничения по адресу увидят адрес прокси, а не игрока.

## Переменные окружения

| Переменная | По умолчанию | Что делает |
|---|---|---|
| `GAME_MODE` | `local` | `local` или `public` |
| `PORT` | `3000` | порт сервера |
| `CASES_DIR` | `./cases` | папка с делами (репозиторий `red-thread-secret`) |
| `MEDIA_DIR` | `./media` | арт и музыка миров |
| `DATA_DIR` | `./.data` | снимки партий, история, фото |
| `GAME_URL` | — | адрес для QR, если IP ноутбука определяется неверно |
| `TELEGRAM_URL` | — | канал игры: ссылка в меню и на телефоне в финале |
| `DONATE_URL` | — | страница поддержки: ссылка и QR в меню |
| `TRUST_PROXY` | — | `1` за обратным прокси: адрес игрока берётся из заголовка |
| `REAL_IP_HEADER` | `x-forwarded-for` | заголовок с адресом игрока (`cf-connecting-ip` за Cloudflare) |
| `MAX_ROOMS` | `300` | предел одновременных комнат (в сети) |
| `MAX_SOCKETS_PER_IP` | `150` в сети | предел соединений с одного адреса |
| `MAX_NEW_ROOMS_PER_IP` | `20` | новых комнат с одного адреса за 10 минут |

## Как играть

1. **Лобби.** Каждый на телефоне вводит имя и выбирает сыщика — или роли раздаёт случай. У каждого
   сыщика своя способность; пример её использования виден при выборе и потом на телефоне по кнопке
   сыщика. Способности ускоряют, но ничего не запирают. Кнопка «Правила» в лобби — всё простыми словами
   и с примерами. Ведущий выбирает режимы: смену реплик (вручную или сама), время на ход, выбор сыщиков,
   подсказки помощника.
2. **Пролог.** Смотрите на экран.
3. **Раунд.** Раундов тем меньше, чем больше бригада.
   - *Ходы.* Каждый выбирает комнату и действие: осмотреть место, спросить того, кто там, показать
     улику — или нажать кнопку своей способности. Ходы тайные и одновременные.
   - *Разбор.* Экран показывает, что нашла бригада: реплики озвучены, улики ложатся на доску.
   - *Совещание.* Доска на экране и телефонах. Красная нить между карточками — противоречие.
4. **Обвинение.** Любой может собрать всех — каждый голосует: кто, чем и почему. Попыток две.
   На рассвете обвинение обязательно.
5. **Финал.** Правда, как всё было, и оценка.

Ведущий: вверху экрана «Лобби», пауза (P) и звук. Пробел или → — следующая реплика.

### Дела «на время»

В меню у таких дел пометка «на время». Раундов нет, часы настоящие (30, 45 или 60 минут — выбирает ведущий).
На экране — здание в разрезе с фигурками сыщиков, доска дела и лента находок. Каждый сам ходит по карте
с телефона: переход между комнатами занимает секунды, лестница — дольше; осмотр и разговор тоже идут
по времени. Ответы открываются на телефоне и остаются в журнале, находки сразу ложатся на общую доску.
На доске — вопросы дела: приколите к вопросу подходящие карточки, и доска даст вывод (неверный набор —
минус 45 секунд). Обвинить можно в любой момент: поиск встанет, все проголосуют; ошибка отнимет пять минут.

## Устройство

```
app/            экран (pages/index.vue) и телефон (pages/play.vue), Vue 3 + Nuxt 4, без SSR
server/
  game/         движок партии: раунды или «на время», ходы, доска, обвинение; одна комната — один экземпляр
  routes/_ws.ts WebSocket: вход экрана и телефонов, комнаты, ограничения
  settings/     миры и их бригады сыщиков
  scenario/     каталог; список дел собирается из CASES_DIR при сборке
  utils/        комнаты, раздача медиа, ограничители, режим
shared/types.ts типы сценария и состояния — по ним пишутся дела
media/          арт и музыка миров
public/         шрифты, звуки миров, иконки
tools/          генерация озвучки, музыки, звуков и картинок, проверка сценария, боты
```

Дело — папка `<id>/` в репозитории дел: `index.ts` (`INFO` для экрана и `SCENARIO`), `world.ts`,
`talk.ts`, `case.ts`, рядом `art/`, `voice/`, `music/` и промпты генераторов в `prompts/`.
Типы дело берёт из `@red-thread/types` (это `shared/types.ts`).

## Инструменты

Ключи — в `.env`, в репозиторий не попадают.

- `CASE=<дело> node_modules/.bin/jiti tools/check-scenario.ts` — проверка честности сценария:
  всё достижимо, способности ничего не запирают. Печатает только числа и id.
- `CASE=<дело> node_modules/.bin/jiti tools/voice.ts` — озвучка (ElevenLabs).
- `CASE=<дело> node tools/music.mjs` — музыкальные темы дела, `node tools/sfx.mjs <мир>` — звуки мира.
- `NODE_EXTRA_CA_CERTS=tools/certs/russian_ca_bundle.pem CASE=<дело> SETTING=<мир> node tools/gigachat-art.mjs` —
  иллюстрации (GigaChat); `tools/flux.mjs` — FLUX на Hugging Face.
- `FAST=1 CASE=<дело> node tools/simulate.mjs 5` — боты играют партию; `ONLINE=1` — против
  сервера в режиме «в сети».

Перерисованные картинки, озвучка и музыка подхватываются без пересборки: сервер отдаёт их с диска.

## Безопасность

- В сети: коды комнат из шести знаков, ключ экрана — 144 бита; перебор кодов и ключей ограничен
  по адресу; сообщения больше 16 КБ и флуд закрывают соединение; число комнат и соединений с адреса
  ограничено.
- Заголовки: CSP, запрет встраивания во фрейм, `nosniff`; камера разрешена только дома.
- Контейнер работает не от root.
